# components/ui/

**shadcn/ui** primitives. This folder is managed by the shadcn CLI.

Add a component with:

```bash
npx shadcn@latest add button dialog input
```

Do not hand-edit these files unless you intend to fork a primitive — regenerating
via the CLI will overwrite local changes. Wrap/extend primitives in a sibling
folder (e.g. `components/windows/`) instead.
