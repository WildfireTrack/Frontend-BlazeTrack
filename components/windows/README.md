# components/windows/

Draggable, desktop-style information windows (opened when a wildfire marker is
clicked). Built on **react-draggable** with **Framer Motion** for enter/exit
animation.

Designed for **multiple simultaneous windows**: each window is self-contained and
positioned/z-indexed from window state in `store/`. No window logic is
implemented yet — this is a placeholder for the Phase 1 structure.
